# 🚀 Quick Start Guide

## Adding Your First Album

1. **Create an album folder:**

```bash
mkdir public/albums/my-photos
```

2. **Copy your photos:**

```bash
# Copy photos from your camera or phone
cp ~/Pictures/my-vacation/*.jpg public/albums/my-photos/
```

3. **Add album info (optional):**

```bash
cat > public/albums/my-photos/album.json << 'EOJ'
{
  "title": "My Vacation Photos",
  "description": "Summer trip 2024"
}
EOJ
```

4. **Generate album data:**

```bash
yarn generate-albums
```

5. **Start the app:**

```bash
yarn dev
```

6. **View in browser:**
Open <http://localhost:4321>

## Features You Can Use

### Viewing Photos

- Click any album to see its photos
- Click a photo to open the lightbox viewer
- Use arrow keys (← →) to navigate
- Press ESC to close the lightbox
- Click the photo to zoom in/out

### EXIF Data

The app automatically extracts:

- Date taken
- Camera & lens info
- Location (if GPS data exists)
- Camera settings (aperture, ISO, etc.)

### Customizing Albums

Edit `src/data/albums.json` after running `yarn generate-albums` to add:

- Photo titles
- Captions
- Tags

Example:

```json
{
  "filename": "sunset.jpg",
  "url": "/albums/my-photos/sunset.jpg",
  "title": "Beautiful Sunset",
  "caption": "Taken from the beach",
  "tags": ["nature", "sunset", "beach"]
}
```

## Project Structure

```
public/albums/          ← Add your photos here
  ├── album-1/
  │   ├── album.json   ← Album metadata
  │   ├── photo1.jpg
  │   └── photo2.jpg
  └── album-2/
      └── photos...

src/data/
  └── albums.json      ← Generated by yarn generate-albums
```

## Common Tasks

### Add more photos to existing album

```bash
cp ~/new-photos/*.jpg public/albums/my-photos/
yarn generate-albums
```

### Create another album

```bash
mkdir public/albums/another-album
cp ~/more-photos/*.jpg public/albums/another-album/
yarn generate-albums
```

### Build for deployment

```bash
yarn build
# Output in dist/ folder
```

That's it! Enjoy your photo album! 📸

## Alpine.js Integration

Alpine.js has been added for interactive features! 🎉

### View the Demo

```bash
yarn dev
# Then visit: http://localhost:4321/gallery-demo
```

### What's Available

**PhotoGallery Component** - Full gallery with filtering, lightbox, keyboard nav

```astro
import PhotoGallery from '../components/PhotoGallery.astro';
<PhotoGallery photos={photos} />
```

**PhotoCard Component** - Photo card with persistent likes

```astro
import PhotoCard from '../components/PhotoCard.astro';
<PhotoCard src="/photo.jpg" alt="..." title="..." />
```
